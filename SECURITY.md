# Politique de sécurité

## Versions supportées

Seule la dernière version publiée de StarHubFR (voir [Releases](../../releases)) reçoit des correctifs de sécurité.

## Signaler une vulnérabilité

StarHubFR télécharge et installe des archives de mods (.zip, .7z, .rar) provenant de Nexus Mods. Si vous découvrez une vulnérabilité liée à :

- l'exécution ou l'extraction d'archives malveillantes,
- la gestion des identifiants ou clés API (Nexus, traduction),
- une injection de code via un fichier de configuration ou de mod,

merci de **ne pas ouvrir d'issue publique**. Contactez plutôt le mainteneur directement via un message privé GitHub (profil [mrbabilo](https://github.com/mrbabilo)) en décrivant :

1. La version de StarHubFR concernée.
2. Les étapes de reproduction.
3. L'impact potentiel.

Un correctif sera priorisé et une nouvelle release publiée dès que possible. Le rapporteur sera crédité dans le CHANGELOG (sauf demande contraire).

## Bonnes pratiques utilisateurs

- Téléchargez toujours les mods depuis des sources officielles (Nexus Mods) via le flux intégré à StarHubFR.
- Vérifiez la réputation et les commentaires d'un mod avant installation, surtout pour les mods peu téléchargés.
- Tenez StarHubFR à jour : chaque release peut corriger des problèmes de sécurité liés à l'extraction d'archives.
