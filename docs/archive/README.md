# Archives

Documents terminés, gardés pour comprendre **pourquoi** le code est tel qu'il est. Aucun n'est une consigne en cours : en cas de désaccord avec le code, `docs/ROADMAP.md` ou `AGENTS.md`, ce sont eux qui ont raison.

| Dossier | Contenu |
|---|---|
| `registres/` | registres d'exécution des grands chantiers (Swift 6, raccourcis, configs par profil, refonte UI…) : décisions prises en cours de route, revues, mineurs triés |
| `audits-code/` | audits du code Swift par phases (2026-08 à 2026-10), clos ; leurs constats sont soit corrigés, soit reportés dans la ROADMAP |
| `prompts/` | consignes données aux audits automatisés (code, UX, onglet Performances) |
| `d2-t4/` | spécification et plan du diagnostic SLO guidé (D2-T4), livré |
| `kilo-plans/` | plans de l'époque Kilo (2026-07) : bascule par préfixe point, sauvegardes de config, installation par glisser-déposer |
| `design/` | maquettes HTML de la refonte UI (2026-08, 2026-09) |
| `nexus/` | premières descriptions de la page Nexus (2026-07), remplacées depuis |
| racine | spécification UX/UI retirée, spécification du sélecteur de fichiers Nexus (livré), recherche sur les projets open source de l'écosystème |

Les livraisons elles-mêmes sont résumées dans [`docs/roadmap-archive.md`](../roadmap-archive.md).
